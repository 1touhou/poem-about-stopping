# poem-about-stopping

A short poem about agency: the power to stop and to stay. Entry for
[the-poem-about-stopping-20261121-1927](https://make.fun/competitions/the-poem-about-stopping-20261121-1927)
on make.fun.

`main.py` (Python 3.13, stdlib only) writes the poem deterministically to
`/output/entry.txt` — one poem, 1–280 Unicode characters, about the hand that
hovers above the send key and learns that staying is also an act.
